# Extension Icons

For this PoC, you can use placeholder icons or generate simple icons.

## Quick Setup (Temporary Placeholders)

You can create simple colored squares as placeholders:

1. Go to https://via.placeholder.com/
2. Download these placeholder images:
   - https://via.placeholder.com/16/3b82f6/ffffff?text=CA - Save as `icon16.png`
   - https://via.placeholder.com/32/3b82f6/ffffff?text=CA - Save as `icon32.png`
   - https://via.placeholder.com/48/3b82f6/ffffff?text=CA - Save as `icon48.png`
   - https://via.placeholder.com/128/3b82f6/ffffff?text=CA - Save as `icon128.png`

## Or Create Real Icons

For production, use a tool like:
- Figma (design custom icons)
- Canva (design from templates)
- Icon generators online

Place all 4 icon sizes in this directory:
- icon16.png (16x16)
- icon32.png (32x32)
- icon48.png (48x48)
- icon128.png (128x128)
